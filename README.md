## 🎯 ChatGPT Clone Project

Located in: `/django` folder

### Description
An intelligent chatbot application built with Django that mimics ChatGPT functionality. This is a personal project showcasing full-stack web development with AI integration.

### Features
- Conversational AI interface
- Django backend architecture
- HTML/CSS frontend
- Real-time chat functionality
- User-friendly UI/UX

### Tech Stack
- **Backend**: Django (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: Django ORM (SQLite/PostgreSQL)
- **AI Integration**: API-based AI responses

### Getting Started with ChatGPT Clone

1. Navigate to the django folder:
   ```bash
   cd django
   ```

2. Install dependencies:
   ```bash
   pip install django
   ```

3. Run migrations:
   ```bash
   python manage.py migrate
   ```

4. Start the development server:
   ```bash
   python manage.py runserver
   ```

5. Access the application at `http://localhost:8000`
